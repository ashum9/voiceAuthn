## ECAPA-TDNN Neural Network

```
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│                              ECAPA-TDNN ARCHITECTURE                                     │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│   RAW AUDIO ──► FEATURE EXTRACTION                                                      │
│   ┌─────────────┐  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐                   │
│   │  Pre-Emph   │─►│    STFT     │─►│  Mel Filter │─►│  Log + DCT  │                   │
│   │  α = 0.97   │  │  25ms/10ms  │  │   80 Bands  │  │   80 MFCC   │                   │
│   └─────────────┘  └─────────────┘  └─────────────┘  └──────┬──────┘                   │
│                                                             ▼                           │
│   FRAME-LEVEL PROCESSING                                                                │
│   ┌─────────────────────────────────────────────────────────────────────────────────┐  │
│   │              Conv1D Layer (C=1024, K=5) + BatchNorm + ReLU                      │  │
│   └────────────────────────────────────┬────────────────────────────────────────────┘  │
│                                        ▼                                                │
│   ┌─────────────────────────────────────────────────────────────────────────────────┐  │
│   │  ┌─────────────────────────────────────────────────────────────────────────┐    │  │
│   │  │            SE-Res2Block #1         SE-Res2Block #2         SE-Res2Block #3  │    │  │
│   │  │            Dilation = 2            Dilation = 3            Dilation = 4  │    │  │
│   │  │                                                                          │    │  │
│   │  │  Input ──┬──► Conv1D ──► BN ──► ReLU ──┬──► Squeeze-Excitation ──► + ──►│    │  │
│   │  │          │                             │                                 │    │  │
│   │  │          └───────────(Skip Connection)─┘                                 │    │  │
│   │  │                                                                          │    │  │
│   │  │  Res2Net Multi-Scale: [S1][S2][S3][S4][S5][S6][S7][S8]                   │    │  │
│   │  └─────────────────────────────────────────────────────────────────────────┘    │  │
│   └────────────────────────────────────┬────────────────────────────────────────────┘  │
│                                        ▼                                                │
│   MULTI-LAYER AGGREGATION                                                               │
│   ┌─────────────────────────────────────────────────────────────────────────────────┐  │
│   │  Concat(Block1, Block2, Block3, Conv1) = 4096 channels ──► Conv1D (1536)        │  │
│   └────────────────────────────────────┬────────────────────────────────────────────┘  │
│                                        ▼                                                │
│   ATTENTIVE STATISTICS POOLING                                                          │
│   ┌─────────────────────────────────────────────────────────────────────────────────┐  │
│   │  Frame Features [T×1536] ──► Attention Weights ──► Weighted Mean + Std = 3072   │  │
│   └────────────────────────────────────┬────────────────────────────────────────────┘  │
│                                        ▼                                                │
│   EMBEDDING LAYER                                                                       │
│   ┌─────────────────────────────────────────────────────────────────────────────────┐  │
│   │  Linear (3072→192) ──► BatchNorm ──► L2 Normalize ──► 192-dim Unit Sphere       │  │
│   └─────────────────────────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```
